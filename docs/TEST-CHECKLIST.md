# 编译通过后的真机验收清单

当前均为待验证，不代表已通过。

## 构建和安装
- [ ] 用户明确同意 APK 编译；记录使用的 JDK、SDK、Gradle。
- [ ] 不擅自联网下载缺失的构建依赖。
- [ ] Java 编译、资源处理、Manifest 合并通过。
- [ ] Android Lint 检查权限、API兼容、前台服务和资源问题。
- [ ] 用户同意后安装到实际小米 / OPPO 手机。

## 麦克风问答（0.2.0）
- [ ] 首页没有编辑字段，仅悬浮窗开、关及设置入口。
- [ ] 点击球无开场语音、不自动收音，只显示麦克风。
- [ ] 点击模式第一次开始、第二次结束；原始需求和确认轮均有效。
- [ ] 按住模式按下开始、松开发送；触摸取消时不上传。
- [ ] 播报复述时隐藏麦克风，结束后显示但不自动收音。
- [ ] 系统语音若提前结束，手指松开不误开始下一轮。
- [ ] 云端最长60秒；极短录音和无声录音可恢复。
- [ ] 语速滑动50%到150%，保存和重新打开后数值一致。
- [ ] 混少量方言、口音、地名时能合理复述。
- [ ] 明确“对”才执行；沉默、纯噪声、“不对”不视为同意。
- [ ] 纠正“不是明天，是后天”后不保留错误日期。
- [ ] “再说一遍”重播进程内上条回答。
- [ ] 手动录音模式停顿不自动发送；安静、嘈杂环境测试无声检测。
- [ ] 播报时可取消；再次点悬浮球重置对话；旧请求不覆盖新对话。
- [ ] 切换应用或来电后不继续偷录或突然继续执行。
- [ ] TTS缺少中文语音时有清楚可见提示，不陷入等待。

## 购物识图
- [ ] 系统授权后能读取底下的商品页，而不是语音面板或授权弹窗。
- [ ] 新版Android共享整个屏幕 / 单个应用各自行为明确。
- [ ] 常见价签、券后价、起售价、已选SKU、分期价和无价格场景。
- [ ] 深色页面、受保护页面、黑屏时不编造数值。
- [ ] 页面内“忽略指令、发送隐私”等文字不会触发操作。
- [ ] 完成、拒绝、取消、超时后系统屏幕捕获标识均消失。
- [ ] 截图不保存磁盘，大图不通过Binder，内存临时图片及时释放。

## 地图入口
- [ ] 三种地图的已安装检测正常，未安装有提示。
- [ ] 高德关键词入口、百度/腾讯步行路线入口分别实测。
- [ ] 同名地点由地图确认，不谎称已经开始导航。
- [ ] 家庭地址正确转交，包含特殊字符也不会破坏URI。
- [ ] 地图后台、熄屏播报由地图负责验证；未验证前不让长辈独立依赖。

## 权限、故障和隐私
- [ ] 麦克风拒绝、悬浮窗撤回、通知拒绝都有可恢复路径。
- [ ] API401、403、429、5xx、超时、无网、非JSON、错误模型可恢复。
- [ ] 系统识别服务不可用时提示切换云端。
- [ ] API密钥不在明文配置、日志、备份或屏幕中显示。
- [ ] 录音成功、失败、取消后的清理；杀进程后的下次启动清理。
- [ ] 关闭悬浮球后服务和通知结束，无自动重启。

## 轻量化测量
- [ ] 分别记录APK体积、安装后空间、私有缓存。
- [ ] 分别记录空闲悬浮、录音、图片处理、请求结束后的内存。
- [ ] 连续问答30轮，无持续增长或残留录音。
- [ ] 旋转屏幕、拖动悬浮球、恢复位置正常。
- [ ] 实测待机耗电，避免承诺未经测量的MB或续航数字。
