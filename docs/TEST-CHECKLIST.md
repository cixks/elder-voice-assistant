## 顶部路线方向箭头（本地实现，未编译、未真机验证）
- [ ] 导航时出现顶部箭头和“本方向约XX米”，切换到其他应用仍可见，不抢键盘焦点、不拦截点击。
- [ ] 距离根据步行路线坐标计算至明显弯道（相对当前段超过30度）或当前导航大路段终点；不是到目的地的直线距离，不使用仅驾车有效的剩余距离接口。
- [ ] 手机屏幕顶部与路线同向时箭头向上，反向时向下；手机向右转90度时箭头相对屏幕向左转90度；跨越359/0度没有整圈跳转。
- [ ] 平放、适度倾斜、横屏、反向横屏和倒置时方向一致；接近竖直、顶部水平投影太小时不显示误导箭头。
- [ ] 指南针低精度、磁干扰、无旋转向量传感器、传感器超过3秒未更新时，箭头变为问号并提示校准/使用语音。
- [ ] 定位超过10秒未更新、精度超过35米、未匹配路线、路线索引无效、位置距匹配线段超过35米时不继续显示旧箭头。
- [ ] 直路距离随行进减少；路口转弯、路线回折、相邻平行路、偏航重算时不指向终点、不跳到错误路段；SDK未提供可用步行索引时宁可显示等待。
- [ ] 偏航重算期间隐藏旧方向，重算成功后使用新路线；重算失败结束导航，不遗留旧箭头。
- [ ] 关闭/撤销悬浮窗权限时语音导航不崩溃，恢复权限后可重新显示；小米/OPPO另测系统后台弹窗限制。
- [ ] 熄屏后最多1秒停止方向传感器，亮屏后重新等待有效朝向；停止、到达、错误、服务销毁均移除悬浮提示并注销传感器。
- [ ] 真机测量新增CPU、耗电和界面遮挡；该箭头只是辅助提示，不能保证复杂磁场、定位漂移或地图错误下绝对准确。
