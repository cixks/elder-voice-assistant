# 顶部步行方向提示

用户已追加授权“先编译看看吧”：本轮以 0.4.2 提交并推送 main，自动触发云端构建。构建结果与真机验收结果分别确认，不能将编译通过当作导航准确性验证。

实现入口：`WalkNaviService`，路线计算：`WalkRouteDirection`，悬浮窗与方向传感器：`WalkDirectionOverlay`。

- 路线方向使用高德导航定位提供的 step/link/point 匹配索引和真实步行路线坐标；不使用手机移动方向或目的地直线方位替代。
- 将当前位置投影到匹配线段，计算前方明显弯道或当前大路段终点的沿路距离。连续弯道以相对当前线段30度为界，因此显示的是近似前方行进距离，不是全程剩余距离。
- 旋转向量传感器提供磁北朝向，按当前屏幕旋转重映射坐标，再叠加当地磁偏角换算真北。箭头角度 = 路线真北方位 - 屏幕顶部真北方位；圆周平滑避免跨0度跳转。
- 不使用不含绝对北向的游戏旋转向量，也不使用GPS速度方向替代手机朝向。缺少可靠方向时显示问号与提示。
- 方向传感器只在导航、亮屏且允许悬浮窗期间注册，UI采样频率；熄屏/权限状态每秒检查，停止立即释放。不引入新的依赖、图片文件或网络调用。
- 权限缺失时语音导航仍保留，导航启动摘要提醒开启悬浮窗权限。系统额外的后台弹窗限制仍需小米/OPPO真机验证。

## 限制与安全

高德文档中部分 NaviInfo 剩余距离接口注明仅驾车有效，所以本功能没有依赖这些值。若步行回调不提供有效的匹配索引、点集或位置时间，保守显示“确认中”，不尝试猜测方向。当前匹配点在link末点、重复坐标点时也可能短暂等待下一次有效定位。

定位和磁传感器都可能有误，不能承诺“确保方向绝对正确”。首次必须由家人陪同，按 `TEST-CHECKLIST.md` 验证，不可仅凭箭头过马路或忽略现实道路标志。
